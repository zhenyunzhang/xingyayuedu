## 诗文核验（大人用）

本页采用通行教材 / 《唐诗三百首》常见版本：

> 床前明月光，疑是地上霜。  
> 举头望明月，低头思故乡。

宋本《李太白文集》等古籍常见异文为「床前看月光」「举头望山月」。儿童教材取通行易读版本；异文不是孩子读错。

- 维基文库《静夜思》（并列多版本）：https://zh.wikisource.org/wiki/靜夜思

## 故事小课里讲了什么

- 李白在外旅行，夜里看见床前月光  
- 「疑是地上霜」：月光亮得像霜的儿童化讲解  
- 抬头望月、低头想家  
- 拓展：古人爱月亮、中秋赏月；同一轮月亮连接远方亲人  
- 想家是心里有爱的人，温和不沉重
