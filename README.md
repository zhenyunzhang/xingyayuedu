# 星芽阅读

面向 3–6 岁儿童的古诗动画启蒙 HTML 教材。

## 在线访问

GitHub Pages 部署后地址：

- 首页：https://zhenyunzhang.github.io/xingyayuedu/
- 《静夜思》：https://zhenyunzhang.github.io/xingyayuedu/jing-ye-si/
- 《送杜少府之任蜀州》：https://zhenyunzhang.github.io/xingyayuedu/song-du-shao-fu/

## 目录

```text
docs/
├── index.html          # 课程入口页
├── jing-ye-si/         # 《静夜思》
└── song-du-shao-fu/    # 《送杜少府之任蜀州》
```

## 本地预览

```bash
cd docs/jing-ye-si
python3 -m http.server 8766
```

浏览器访问 `http://localhost:8766/`。
