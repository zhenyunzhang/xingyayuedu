一起读古诗

点下面听温柔朗读。听的时候故事动画会安静下来。

静夜思

唐 · 李白

chuáng qián míng yuè guāng 床前明月光，
yí shì dì shàng shuāng 疑是地上霜。
jǔ tóu wàng míng yuè 举头望明月，
dī tóu sī gù xiāng 低头思故乡。

诗里藏着四幅画

点开每一句，看看小画，再听懂意思。

1

床前明月光，

床前一片亮亮的光。

安静的夜里，床前忽然亮起来，那是月亮送来的光。

2

疑是地上霜。

好像地上铺了白霜。

月光太白了，乍一看还以为是地上的霜呢。

3

举头望明月，

抬起头看月亮。

抬起头，望着天上那轮又圆又亮的月亮。

4

低头思故乡。

低下头，想起家乡。

低下头，心里想起长大的那个家，还有爱的人。

给大人的陪读小纸条

不要求一次背会，先让孩子看见月亮、感到温暖。

今天可以聊什么？

晚上如果看见月亮，问问孩子：“月亮照到我们，也会照到谁呀？”把想家讲成心里有爱。

做一个小动作

和孩子一起：先抬头看月亮（或月亮图片），再摸摸胸口说“我想家/我想你”，对应举头与低头。
